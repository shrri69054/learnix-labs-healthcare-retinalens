RetinaLens

A deep learning pipeline that screens retinal fundus photographs for referable glaucoma and shows which regions of the eye drove each decision.

View code on GitHub Try the preprocessing lab

The problem

Glaucoma damages the optic nerve and often causes no symptoms until vision is already lost. Screening programs capture fundus photos, but specialists are scarce. RetinaLens classifies each photo as referable glaucoma (RG) or non-referable (NRG) so likely cases can be sent to a clinician sooner.

9,540fundus images in the metadata

4,000 / 385 / 385train, validation, test images per class
3preprocessing variants: crop, pad, raw

How it works

  1. PreprocessResize to 224×224, normalize, augment with flips, rotation and color jitter.
  2. ClassifyEfficientNet-B0 pretrained on ImageNet, fine-tuned for one glaucoma probability.
  3. Choose thresholdDecision cut-off picked on the validation set using Youden's J.
  4. ExplainGrad-CAM heatmap marks the retinal regions behind the prediction.
  5. ServeFlask app takes an uploaded image and returns verdict, probability and heatmap.

Run the full model

This page is the project overview. Predictions come from the trained PyTorch model, which runs from the repository:

pip install -r requirements.txt
bash prepare_data.sh archive.zip
python train.py
python evaluate.py
python app.py
RetinaLens is a student research project and not a medical device. It does not replace an eye examination by a qualified clinician.
